# PAE 分析结果：内部置信度无法解释预测能力差异

日期：2026-10-27

## 一、为什么要做 PAE 分析

此前只用了 pLDDT（单残基置信度），而"磷酸化是否引起结构域相对移动"本质上是
**残基对之间**的问题，对应 AF3 的 PAE（Predicted Aligned Error）矩阵。
这是项目内最后一个未使用的 AF3 原生指标。

## 二、指标定义

| 指标 | 含义 |
|---|---|
| `pae_global` | 全矩阵均值（整体确定性） |
| `pae_site_to_rest` | 位点区（±10 残基）→ 其余残基的平均 PAE |
| `pae_site_internal` | 位点区内部平均 PAE |
| `delta_*` | phos 相对 unphos 的变化（正 = 磷酸化后更不确定） |

## 三、静态 PAE 无预测力

| 指标 | 与幅度比的相关 |
|---|---|
| 全局 PAE | r = +0.234 |
| 位点→其余 PAE | r = −0.031 |
| 位点内部 PAE | r = −0.321 |

静态置信度与预测能力几乎无关。

## 四、ΔPAE 曾看似显著，实为单点假象

`delta_pae_site_to_rest` 与幅度比：**r = +0.613, n = 15, p = 0.015（显著）**

但这个显著性**完全由 IRF3 一个点驱动**：

| 检验 | 结果 |
|---|---|
| 剔除 IRF3 后 | **r = +0.125**（从 0.613 崩塌） |
| 纯净配对子集（n=9） | **r = +0.056**（几乎为零） |
| 混杂配对子集（n=6） | r = +0.790（小样本，不可信） |

**IRF3 的 ΔPAE = +6.46，幅度比 = 2.70**，是唯一的极端点（也是唯一被高估的蛋白），
单点即可左右整条回归线。见 `Fig5_pae_leverage.pdf` 的双面板对比。

## 五、结论

**AF3 的内部置信度指标（pLDDT、PAE）都无法解释其磷酸化预测能力的差异。**

这已是本项目第二次证伪同类假设：
- 第一次：位点区 pLDDT（n=6 时 r=0.649 → n=11 时 r=0.310）
- 第二次：ΔPAE（整体 r=0.613 → 剔除单点 r=0.125，纯净子集 r=0.056）

## 六、方法学教训（写入论文）

1. **必须做杠杆点检查**：n < 20 时，单个极端点可制造 p < 0.05 的假象。
   本项目的标准流程应包含"逐个剔除后 r 的变化"。
2. **必须分纯净/混杂子集验证**：混杂配对引入的方差会扭曲相关性。
3. **内部置信度 ≠ 预测正确性**：AF3 对某区域的"确信程度"与其在该区域的
   "实际准确度"是两件事，此前文献中常有混淆。

## 七、下一步方向调整

既然 AF3 内部指标解释不了差异，应转向**结构本身的可预测性特征**：

1. 位移的几何类型（整体平移 / 铰链旋转 / 局部重排）—— 优先级最高
2. 位点的溶剂可及性与二级结构
3. 训练数据中同类构象变化的丰富程度

这三项都独立于 AF3 的置信度输出，是目前唯一没被排除的解释路径。
